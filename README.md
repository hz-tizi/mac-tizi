# 梯子 · macOS 代理面板

一个给自己用的 macOS 小面板：**看流量、看谁在走代理、一键切模式、改分流白名单**，配一台 **VLESS + Reality** 服务器使用。

默认规则只有一条：**除了白名单里的域名，其他全部直连。** 国内网站不会绕道美国，只有你点名的网站才出国。

> 这份代码是"客户端 + 运维面板"。**服务器要你自己先搭好**（见 [docs/服务器端.md](docs/服务器端.md)）。
> 源码里**不含任何服务器地址、密钥或密码**，全部从 `config.json` 读取。

> ⚠️ **名字说明**：本项目用的是 [XTLS/Xray-core](https://github.com/XTLS/Xray-core)（网络代理内核）。
> 它和长亭科技的 [xray 漏洞扫描器](https://github.com/chaitin/xray) **只是重名，毫无关系**。

---

## 这是什么 / 不是什么

**一句话：它是一个运行在你自己 Mac 上的本地软件，不是网站、不是服务、更不是机场。**

| ✅ 这是 | ❌ 这不是 |
|---|---|
| 一个**装在本机**的 macOS 应用（SwiftUI 单文件 + 一组 shell/python 脚本） | 不是一个网站或在线服务，没有任何"登录入口" |
| 一块**仪表盘 + 开关**：看流量、看谁在走代理、切模式、改白名单 | 不提供节点、不提供订阅、不提供账号、不收钱 |
| 它通过 **SSH 读你自己服务器**的状态（CPU、流量、连接数） | 不会把你的数据发给任何第三方，没有统计上报 |
| 代理能力来自 **你自己的服务器 + 本机 Xray 内核** | 不是"填个地址就能白嫖"的客户端 |

**所以：**

- 你有自己的 VPS（已搭好 VLESS + Reality）→ 填上 `config.json`，装完就能用；
- **没有服务器的人，装了也用不了** —— 它只是个"遥控器"，不是"电视节目"。
- 所有真实地址、密钥只存在你本机的 `config.json` 和 `client.json` 里，**永远不会进仓库**。

## 界面（六个页面）

| 页面 | 内容 |
|---|---|
| **总览** | 安全分圆环、24 小时 / 7 天流量曲线、延迟丢包、左右两个程序面板（谁在走代理 / 谁在直连） |
| **安全检查** | 17 项体检（端口、证书、防火墙、密钥登录、内存磁盘、到期…），一键跑，出 OK / WARN / BAD |
| **流量** | 今日 / 本月 / 累计 / 峰值，程序流量排行（可切 24 时 / 3 天 / 7 天 / 1 月） |
| **服务器** | CPU、内存、磁盘、负载、运行时长、出口 IP（点一下复制）、重启 / 关机 |
| **分流规则** | 白名单增删，输入程序名可自动带出候选域名 |
| **设置** | 套餐管理（总量 / 已用基数 / 到期日）、清理缓存、IP 登录限制开关 |

三种模式：

- **智能**（默认）：白名单 → 服务器；其余 → 直连
- **全局**：全部 → 服务器
- **直连**：全部不走代理

## 它是怎么工作的

```
浏览器 / App
   ↓  系统代理（手动，指向 127.0.0.1:10808）
本地 Xray 内核
   ├─ 域名在「规则.txt」白名单里 → 走 443 到你的服务器（Reality 伪装）
   └─ 其他域名                  → 直接从本机出去（直连）
```

**为什么不用 PAC：** 实测部分 macOS 上 PAC 不生效，会出现"白名单里的站也打不开"。
改成"系统代理全量 + 内核按域名分流"后，行为可预测、可验证。

面板上的数据，一半来自本机（`lsof` 看谁连着 10808、`nettop` 算流量、读 Xray 访问日志），
一半来自服务器（一条 SSH 命令跑 `/root/ltcollect.py`，取 CPU / 内存 / 流量 / 探测次数）。

## 前置条件

1. macOS 13+（Apple Silicon 或 Intel，默认按 arm64 编译）
2. 一台已经跑起 **VLESS + Reality** 的服务器（Xray），并且**已配好 SSH 免密登录**
3. 本机装了 Xray 内核，放在 `~/Library/Application Support/Tizi/xray-local/`
   - `xray`（可执行文件）
   - `client.json`（指向你服务器的客户端配置）

## 三步安装

```bash
git clone <这个仓库>
cd MacTizi

# 1) 编译
bash build.sh

# 2) 填配置（服务器地址 / SSH 端口）
cp config.example.json config.json
$EDITOR config.json

# 3) 安装（脚本 + App + 开机自启）
bash install.sh
```

然后打开「梯子」，顶栏点 **智能**。

## 配置项 `config.json`

| 键 | 说明 | 示例 |
|---|---|---|
| `host` | 服务器 IP 或域名 | `"1.2.3.4"` |
| `sshPort` | SSH 端口 | `22` |
| `sshUser` | SSH 用户名 | `"root"` |
| `expire` | 服务器到期日（面板显示"还剩几天"） | `"2026-12-01"` |
| `xrayLabel` | 内核的 launchd 标签名 | `"com.tizi.xray"` |

> 这个文件**已经在 `.gitignore` 里**，不会误提交。

服务器端还需要一个 `/root/ltcollect.py` 采集脚本，见 [docs/服务器端.md](docs/服务器端.md)。

## 分流规则怎么加

白名单文件：`~/Library/Application Support/Tizi/规则.txt`

```
proxy|*.youtube.com
proxy|*.googlevideo.com
```

也可以在面板「分流规则」里输入域名点添加，输入程序名点「查域名」会自动带出候选域名。

**加"全套"很重要**：只加主站会出现"首页能开、图片不显示、视频黑屏"，因为图片和视频在别的域名上。

## 安全设计

| 项 | 做法 |
|---|---|
| 监听范围 | 内核只监听 `127.0.0.1:10808`，局域网连不进来 |
| 权限 | `client.json`、日志、账本一律 `600`；数据目录 `700` |
| 不收集数据 | 面板只读本机状态和**你自己服务器**的数据，不向任何第三方上报 |
| 不含密钥 | 源码与配置里没有 UUID / 私钥 / 密码；这些只存在于你的 `client.json` |
| SSH | 只读取数据，不修改服务器（重启/关机需要你在面板里点） |

## 常见问题

**数据全是 0 / 显示"离线"**
→ 一般是 SSH 不通。终端执行 `ssh -p 端口 用户@服务器` 试一下；面板会保留上一次数据，不会清空。

**面板说"隧道不通"，但网页能开**
→ 检查白名单里有没有 `www.gstatic.com`（体检用它测）。你也可以自己改 `体检.sh` 里的测试地址。

**改了脚本不生效**
→ 这些脚本在 `~/Library/Application Support/Tizi/`，改完记得 `bash install.sh` 重新复制。

**打开提示"未验证的开发者"**
→ 本项目是临时签名（ad-hoc）。首次打开：右键 → 打开。

## 已知限制

- 只有 mac 端，没有 iOS / Android 客户端
- 面板数据依赖 SSH，断网时只能看缓存
- 程序归属是"按端口快照"，一闪而过的短连接会漏
- 只支持 Apple Silicon 开箱编译（Intel 改 `build.sh` 里的 `-target`）
- 不支持自动更新
