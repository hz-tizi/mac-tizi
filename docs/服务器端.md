# 服务器端怎么配

> 这份文档只写"最小可用"，不含任何真实密钥。

## 1. 装 Xray

```bash
bash -c "$(curl -L https://github.com/XTLS/Xray-install/raw/main/install-release.sh)" @ install
```

## 2. 生成 Reality 密钥

```bash
xray x25519          # 得到 Private key / Public key
xray uuid            # 节点 UUID
openssl rand -hex 8  # shortId（8 字节）
```

## 3. 写服务端配置 `/usr/local/etc/xray/config.json`

```json
{
  "log": { "loglevel": "warning", "access": "/var/log/xray/access.log" },
  "inbounds": [{
    "port": 443,
    "protocol": "vless",
    "settings": {
      "clients": [{ "id": "<你的UUID>", "flow": "xtls-rprx-vision" }],
      "decryption": "none"
    },
    "streamSettings": {
      "network": "tcp",
      "security": "reality",
      "realitySettings": {
        "dest": "www.intel.com:443",
        "serverNames": ["www.intel.com"],
        "privateKey": "<你的私钥>",
        "shortIds": ["<你的shortId>"]
      }
    }
  }],
  "outbounds": [{ "protocol": "freedom" }]
}
```

要点：

- `dest` / `serverNames` 选一个**真实存在的大站**，证书链不要太长
- 只开 443（+ SSH），其余端口关掉
- `xray -test -c /usr/local/etc/xray/config.json` 通过再启动

## 4. 客户端配置（mac 上）

`~/Library/Application Support/Tizi/xray-local/client.json`：

```json
{
  "log": { "loglevel": "warning",
           "access": "~/Library/Application Support/Tizi/xray-local/access.log",
           "error":  "~/Library/Application Support/Tizi/xray-local/error.log" },
  "inbounds": [
    { "listen": "127.0.0.1", "port": 10808, "protocol": "http", "tag": "http-in" }
  ],
  "outbounds": [{
    "protocol": "vless",
    "settings": { "vnext": [{ "address": "<服务器IP>", "port": 443,
      "users": [{ "id": "<UUID>", "encryption": "none", "flow": "xtls-rprx-vision" }] }] },
    "streamSettings": { "network": "tcp", "security": "reality",
      "realitySettings": { "serverName": "www.intel.com", "fingerprint": "chrome",
        "publicKey": "<公钥>", "shortId": "<shortId>", "spiderX": "/" } },
    "tag": "proxy"
  }],
  "routing": { "domainStrategy": "AsIs", "rules": [
    { "type": "field", "domain": [], "outboundTag": "proxy" },
    { "type": "field", "network": "tcp,udp", "outboundTag": "direct" }
  ]}
}
```

> 路由规则由 `客户端路由.py` 按 `规则.txt` 自动重写，手写一次即可。

## 5. 采集脚本（面板数据来源）

保存到 `/root/ltcollect.py`，`chmod 700`。要点：

- 用 `vnstat --json d` / `--json h` 取流量
- 用 `free` / `df` / `/proc` 取资源
- 用 `ss -tn state established '( sport = :443 )'` 取连接数
- 用 `journalctl -u xray | grep -c 'invalid connection'` 数探测
- 输出**一行 JSON**，mac 端直接 `json.loads`

最小示例：

```python
import json, subprocess
def sh(c):
    try: return subprocess.run(c, shell=True, capture_output=True, text=True, timeout=10).stdout
    except Exception: return ""
print(json.dumps({
  "cpu": 0, "mem_used": 0, "mem_total": 0, "disk": 0,
  "today": 0, "conns": 0, "probes": 0
}, ensure_ascii=False))
```

## 6. 加固清单

```bash
ufw allow 443/tcp
ufw allow <你的SSH端口>/tcp
ufw enable
# 关密码登录
sed -i 's/^#*PasswordAuthentication.*/PasswordAuthentication no/' /etc/ssh/sshd_config
systemctl restart ssh
# BBR
echo 'net.core.default_qdisc=fq' >> /etc/sysctl.conf
echo 'net.ipv4.tcp_congestion_control=bbr' >> /etc/sysctl.conf
sysctl -p
```
